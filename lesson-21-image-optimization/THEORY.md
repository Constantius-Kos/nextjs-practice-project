# Урок 21: Оптимізація зображень (next/image)

## Чому стандартний `<img>` — це проблема?
Звичайний тег `<img>` у сучасному вебі — це джерело багатьох проблем з продуктивністю:
1. **Layout Shift (CLS):** Сторінка "стрибає", коли картинка завантажується і розсовує текст.
2. **Великий розмір:** Браузер завантажує оригінальне фото 5МБ, навіть якщо ми показуємо його як маленьку аватарку.
3. **Неефективні формати:** JPEG/PNG важать більше, ніж сучасний WebP або AVIF.
4. **Завантаження всього одразу:** Браузер намагається завантажити картинки навіть у футері, який користувач ще не бачив.

## Як працює `next/image`
Компонент `<Image />` від Next.js — це потужний інструмент, який автоматизує оптимізацію:

1. **Size Optimization:** Автоматично генерує кілька розмірів картинки (через `srcset`) і віддає той, що найкраще підходить під екран користувача.
2. **Visual Stability:** Обов'язкові параметри `width` та `height` (або `fill`) резервують місце на сторінці до завантаження, що прибирає CLS.
3. **Lazy Loading:** Картинки завантажуються тільки тоді, коли вони потрапляють у зону видимості (viewport).
4. **Modern Formats:** Next.js автоматично конвертує картинки в WebP/AVIF (якщо браузер їх підтримує).

## Ключові пропси

### 1. Локальні зображення (Static Imports)
Якщо картинка лежить у проєкті, Next.js автоматично знає її ширину і висоту.
```tsx
import Image from 'next/image'
import profilePic from './me.png'

export default function Page() {
  return <Image src={profilePic} alt="Author" />
}
```

### 2. Віддалені зображення (Remote Images)
Для фото з інших серверів (наприклад, аватарки з GitHub) потрібно:
1. Вказати `width` та `height` вручну.
2. Дозволити домен у `next.config.ts`.
```tsx
<Image 
  src={session.user.image} 
  alt="User profile" 
  width={40} 
  height={40} 
  className="rounded-full"
/>
```

### 3. Режим Fill
Якщо ти не знаєш розміру (наприклад, задня стінка картки), використовуй `fill`. Батьківський елемент МАЄ мати `position: relative`.
```tsx
<div style={{ position: 'relative', width: '300px', height: '200px' }}>
  <Image src="/hero.jpg" alt="Hero" fill className="object-cover" />
</div>
```

---

## Пріоритет (Priority)
Для картинок на першому екрані (Hero images, LCP елементи) додавай пропс `priority`. Це каже Next.js завантажити їх негайно.
```tsx
<Image src="/banner.jpg" alt="Banner" width={1200} height={600} priority />
```
