# Практика: Оптимізація зображень

У цьому уроці ми навчимося використовувати компонент `<Image />` для локальних та віддалених зображень.

---

## 🏗️ Підготовка
Я вже підготував для тебе Hero-зображення `public/hero-nextjs.png`.

---

## 💻 Задачі

### Задача 1: Локальне Hero-зображення
Додай головне зображення на сторінку "Головна".

1. Відкрий `app/page.tsx`.
2. Імпортуй `Image` з `next/image`.
3. Розмісти картинку `/hero-nextjs.png` перед заголовком `<h1>`.
4. Встанови `width={600}` та `height={400}`.
5. **Важливо:** Оскільки це основне зображення на першому екрані (LCP), додай йому пропс `priority`.

### Задача 2: Аватарка з GitHub (Remote Image)
Давай додамо аватарку користувача в хедер поруч з його ім'ям.

1. Відкрий `app/components/Header.tsx`.
2. Використай `session.user?.image` як джерело (`src`).
3. Встанови розмір `width={36}` та `height={36}`.
4. Додай `className="rounded-full"` (Tailwind) для круглої форми.
5. **Налаштування:** Щоб Next.js дозволив завантаження з серверів GitHub, додай `remotePatterns` у файл `next.config.ts`.
   - Домен: `avatars.githubusercontent.com`

---

## 🏆 Челлендж
Знайди або згенеруй ще одну картинку, збережи її в `public` і додай на сторінку контактів (`app/contacts/page.tsx`), але цього разу використай пропс `fill` замість фіксованих розмірів.
> Підказка: Батьківський блок для `fill` має мати `position: relative`.
