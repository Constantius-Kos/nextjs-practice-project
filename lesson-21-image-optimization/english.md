# English for IT (Lesson 21)

| Term | Transcription | Translation | Context in Next.js |
|------|---------------|-------------|-------------------|
| **Layout Shift** | /ˌleɪaʊt ʃɪft/ | Зміщення макета | Коли контент "стрибає" під час завантаження зображення (CLS). |
| **Cumulative Layout Shift (CLS)** | /ˈkjuːmjələtɪv .../ | Сукупне зміщення макета | Метрика Core Web Vitals, що вимірює стабільність сторінки. |
| **Largest Contentful Paint (LCP)** | /ˈlɑːrdʒɪst .../ | Відфарбовування найбільшого контенту | Метрика часу завантаження основного контенту сторінки. |
| **Lazy Loading** | /ˈleɪzi ˈloʊdɪŋ/ | Ліниве завантаження | Завантаження об'єктів тільки тоді, коли вони потрібні. |
| **Placeholder** | /ˈpleɪshoʊldər/ | Заповнювач | Тимчасовий об'єкт (колір або розмите фото), поки вантажиться основне. |
| **Srcset** | /ˈsɜːrs set/ | Набір джерел | Атрибут HTML, що дозволяє вказувати різні файли для різних екранів. |
| **Aspect Ratio** | /ˈæspekt ˈreɪʃioʊ/ | Співвідношення сторін | Відношення ширини до висоти (наприклад, 16:9). |
| **Fill** | /fɪl/ | Заповнити | Режим, коли об'єкт займає весь простір контейнера. |
| **Object-fit** | /ˈɒbdʒɪkt fɪt/ | Вписання об'єкта | CSS-властивість, що визначає, як контент (картинка) вписується в блок. |
| **Cover** | /ˈkʌvər/ | Покриття | Значення, що змушує картинку заповнити блок без деформації. |
| **Contain** | /kənˈteɪn/ | Містити / Вміщати | Значення, що вписує картинку повністю, залишаючи пусті поля. |
