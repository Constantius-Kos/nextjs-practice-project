# 🇬🇧 English for Lesson 16 (Route Handlers)

| Term | Pronunciation | Translation | Context in Next.js |
| :--- | :--- | :--- | :--- |
| **Handler** | /ˈhændlər/ | Обробник | Функція, яка обробляє запит. |
| **Endpoint** | /ˈendpɔɪnt/ | Кінцева точка | URL-адреса, до якої ми звертаємось. |
| **Request** | /rɪˈkwest/ | Запит | Те, що приходить від клієнта. |
| **Response** | /rɪˈspɒns/ | Відповідь | Те, що ми відправляємо назад. |
| **Payload** | /ˈpeɪləʊd/ | Корисне навантаження | Дані, які передаються в тілі запиту (Body). |
| **Status Code** | /ˈsteɪtəs kəʊd/ | Код статусу | 200 (OK), 404 (Not Found), 500 (Error). |
