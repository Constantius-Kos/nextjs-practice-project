# 📋 Резюме уроку 16: Route Handlers

### 1. Ендпоінти (Endpoints)
*   **Файлова структура:** API створюється у файлах `route.ts`. В одній папці не може бути одночасно `page.tsx` та `route.ts`.
*   **Методи:** Ми експортуємо іменовані асинхронні функції для кожного HTTP-методу (`GET`, `POST`, `PUT`, `DELETE` тощо).

### 2. Запити та Відповіді (Request/Response)
*   **NextRequest:** Використовуємо для отримання даних від клієнта (тіло запиту, куки, параметри URL). Читання тіла `req.json()` — завжди асинхронне.
*   **NextResponse:** Використовуємо для відправки даних. Метод `NextResponse.json()` автоматично серіалізує об'єкти та ставить правильні заголовки.

### 3. Кешування API ("use cache")
*   **Next.js 16:** Дозволяє кешувати результати API роутів.
*   **Обмеження:** `"use cache"` можна ставити тільки на функції, що повертають **Plain Objects** (прості дані). Не можна кешувати об'єкт `NextResponse`.
*   **Патерн:** Виносимо отримання даних у кешовану функцію, а `GET` роут просто викликає її та пакує в JSON.
