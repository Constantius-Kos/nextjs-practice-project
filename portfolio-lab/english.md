# 🇬🇧 English Vocabulary — Portfolio Lab

| Термін | Вимова (транскрипція) | Переклад | Контекст у Next.js / CSS | Ментальна асоціація |
| :--- | :--- | :--- | :--- | :--- |
| **Translate** | [тре́нслейт] | **Зсувати / Переміщати** | `translate-x-4`, `translate-y-1` — зсув елемента по горизонталі чи вертикалі | "Перекласти з місця на місце" |
| **Duration** | [дьюрей́шн] | **Тривалість** | `duration-300`, `duration-500` — тривалість анімації у мілісекундах (ms) | Тривалість відео чи пісні |
| **Ease-out** | [із-а́ут] | **Плавний вихід (сповільнення)** | `ease-out`, `ease-in` — крива швидкості (старт швидкий, фініш м'який) | Автомобіль плавно під'їжджає до зупинки |
| **Rotate** | [роуте́йт] | **Повертати / Обертати** | `rotate-6`, `rotate-45` — кут обертання елемента в градусах (deg) | Обертання керма |
| **Scale** | [скейл] | **Масштабувати** | `scale-105`, `scale-110` — зміна розміру елемента відносно 100% | Масштаб карти у зумі |
| **Transition** | [трензи́шн] | **Перехід / Плавність** | `transition`, `transition-transform` — вмикає режим плавного переходу між станами | Регулятор яскравості (димер) замість різкого вимикача |
| **Repository** | [ріпо́зіторі] | **Сховище / Репозиторій** | Сховище коду на GitHub з усіма файлами та проєктами | "Склад із кодом" |
| **Assignment** | [оса́йнмент] | **Завдання / Задача** | Практичні завдання та вправи під час навчання | "Домашня робота чи таск" |
| **Pet Project** | [пет про́джект] | **Особистий проєкт** | Проєкт для душі та практики, створений у вільний час | "Домашній улюбленець серед проєктів" |
| **i18n** | [ай-ейті́н-ен] | **Інтернаціоналізація (Багатомовність)** | Загальний термін для підключення багатьох мов на сайті | `i` + 18 літер + `n` у слові Internationalization |
