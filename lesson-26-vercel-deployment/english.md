# English for Lesson 26: Deployment & Production

### 🔑 Key Vocabulary:
1.  **Deployment** [dɪˈplɔɪmənt] — Розгортання (процес публікації сайту).
2.  **Environment Variables** [ɪnˈvaɪrənmənt ˈvɛəriəblz] — Змінні оточення.
3.  **Production** [prəˈdʌkʃən] — Фінальна версія сайту для користувачів.
4.  **Middleware** [ˈmɪdlˌwɛər] — Проміжне ПЗ для контролю запитів.
5.  **Redirect** [ˌriːdaɪˈrɛkt] — Перенаправлення користувача.
6.  **Cookie Prefix** [ˈkʊki ˈpriːfɪks] — Префікс куків (наприклад, `__Secure-`).
7.  **Serverless** [ˈsɜːvəlɪs] — Безсерверні обчислення (як функції Vercel).
8.  **Diverged history** [daɪˈvɜːdʒd ˈhɪstəri] — Розбіжна історія (ситуація в Git після `--amend`).
9.  **Force push** [fɔːs pʊʃ] — Примусове відправлення коду в репозиторій.
10. **Prefetching** [priːˈfɛtʃɪŋ] — Попереднє завантаження даних.

### 🗣 Useful Phrases:
- **"It works on my machine!"** — *"На моєму комп'ютері це працює!"* (Вічна фраза розробників).
- **"Check the build logs for errors."** — *"Перевір логи збірки на наявність помилок."*
- **"Environment variables are not defined on Vercel."** — *"Змінні оточення не задані на Vercel."*
- **"The deployment was blocked due to an author mismatch."** — *"Деплой було заблоковано через невідповідність автора."*
- **"HTTPS requires secure cookies."** — *"HTTPS потребує безпечних кук."*
