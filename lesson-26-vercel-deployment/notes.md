# Нотатки розробника: Lesson 26 (Vercel)

### 💡 Важливі відкриття:
- **Cookie Debugging**: Якщо Localhost працює, а Vercel (HTTPS) робить нескінченні редиректи — 99%, що справа в префіксі `__Secure-authjs.session-token`.
- **Git Config**: Якщо `git push` не запускає деплой на Vercel (Hobby plan), перевір, чи збігається `git config user.email` із поштою акаунта.
- **Next.js 16 (PPR)**: Навіть якщо сторінка здається статичною, доступ до заголовків (`headers()`) або кук перетворює її на динамічну і вимагає `Suspense` для коректного білду.
- **GitHub OAuth**: Для продакшену обов'язково треба створювати ОКРЕМУ апку в GitHub з правильною `Homepage URL` та `Callback URL` (`.../api/auth/callback/github`).
