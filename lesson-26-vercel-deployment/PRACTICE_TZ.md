# Практичне завдання до Уроку 26: Деплой 🌍

## Task 1: Локальна перевірка (Dry Run)
Перед тим як деплоїти, треба переконатися, що проект взагалі збирається.
1. Зупини `npm run dev`.
2. Запусти команду `npm run build`.
3. Уважно прочитай термінал. Якщо є помилки TypeScript або лінтера — виправ їх. 
   *(Саме цей процес відбуватиметься на сервері Vercel).*

## Task 2: Підготовка до GitHub
Vercel найзручніше працює через Git.
1. Переконайся, що в тебе закоммічені всі останні зміни.
2. Перевір, що `.env.local` точно в `.gitignore`.
3. Пуш код у свій репозиторій на GitHub.

## Task 3: Деплой на Vercel
1. Зайди на [vercel.com](https://vercel.com) та авторизуйся через GitHub.
2. Натисни **"Add New" -> "Project"**.
3. Імпортуй свій репозиторій `NextJS-Learning` (або окремо `practice-project`).
4. **Важливо:** У розділі **Environment Variables** додай усі ключі, які ми використовували (Auth secrets, DB URLs, твій `STUDENT_SECRET` тощо).
5. Натисни **"Deploy"**.

## Task 4: Перевірка результату
1. Після завершення білду відкрий отримане посилання.
2. Спробуй залогінитися (якщо Auth.js налаштовано правильно для production URL).
3. Перевір, чи працює Middleware (redirects) на живому сайті.
