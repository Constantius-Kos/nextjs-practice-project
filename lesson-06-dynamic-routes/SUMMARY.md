# 📋 Резюме уроку 6: Динамічні маршрути (Dynamic Routes)

### 1. Що таке динамічні роути?
- Коли тебе сотні сторінок одного типу (блоги, товари), ти не створюєш їх вручну. Ти створюєш **шаблон**.
- Папка в квадратних дужках `[slug]` стає динамічним параметром у URL.

### 2. Види сегментів
- **`[slug]`**: Один рівень (наприклад, `/blog/hello-world`).
- **`[...slug]` (Catch-all)**: Перехоплює всі вкладені рівні в масив (наприклад, `/shop/shoes/nike/air-max` -> `['shoes', 'nike', 'air-max']`).
- **`[[...slug]]` (Optional Catch-all)**: Працює як попередній, але відкривається і за базовою адресою (наприклад, просто `/shop`).

### 3. Next.js 16: Асинхронні параметри
- **Головна зміна**: Всі динамічні пропси (`params`, `searchParams`) тепер є **Promise**.
- **Як використовувати?** Обов'язково додавай `await`:
  ```tsx
  export default async function Page({ params }: { params: Promise<{ slug: string }> }) {
    const { slug } = await params;
    return <h1>Стаття: {slug}</h1>;
  }
  ```

### 4. Отримання даних на Клієнті
- Якщо тобі потрібен ID з URL всередині клієнтського компонента, використовуй хук **`useParams()`**. Він повертає об'єкт з параметрами автоматично.

### 5. Static Params (Оптимізація)
- Для покращення продуктивності можна використати функцію `generateStaticParams()`. Вона підказує Next.js які сторінки можна згенерувати заздалегідь під час білду (SSG).
