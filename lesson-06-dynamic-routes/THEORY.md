# 📌 Урок 7: Динамічні маршрути (Dynamic Routes)

## 🎯 Мета
- Навчитися створювати сторінки з динамічними URL (наприклад, `/blog/my-post`).
- Зрозуміти різницю між `[slug]`, `[...slug]` та `[[...slug]]`.
- Навчитися отримувати параметри з URL у Server та Client компонентах.

---

## 📖 Теорія

### 1. Що це таке?
Уяви, що у тебе є блог із 100 статтями. Ти не будеш створювати 100 папок вручну. Замість цього ти створюєш одну папку зі спеціальною назвою в квадратних дужках: `app/blog/[slug]/page.tsx`.

Тепер будь-який URL на кшталт `/blog/react`, `/blog/nextjs` або `/blog/hello-world` буде відкривати **одну і ту саму сторінку**, але з різними даними.

### 2. Види динамічних роутів:

1.  **`[slug]` (Звичайний)**
    - URL: `/blog/post-1`
    - Результат: `{ slug: 'post-1' }`
2.  **`[...slug]` (Catch-all)**
    - URL: `/shop/clothes/tops/t-shirts`
    - Результат: `{ slug: ['clothes', 'tops', 't-shirts'] }` (масив!)
3.  **`[[...slug]]` (Optional Catch-all)**
    - Працює як попередній, але також відкривається і за адресою `/shop` (без параметрів).

### 3. Як отримати дані в Next.js 16?

**На сервері (Server Component):**
У Next.js 16 пропси `params` та `searchParams` є асинхронними. Їх треба "розгорнути" через `await`.

```tsx
export default async function Page({ params }: { params: Promise<{ slug: string }> }) {
  const { slug } = await params;
  return <h1>Стаття: {slug}</h1>;
}
```

## ✍️ Практика

### Задача 1: Прості динамічні маршрути
Створимо розділ "Проєкти", де кожен проєкт матиме свою сторінку.

**Кроки:**
1. Створи папку `app/projects/[id]`.
2. Створи всередині `page.tsx`.
3. Виведи на сторінці текст: "Це сторінка проєкту №..." (замість точок має бути ID з URL).
4. Додай у файл `next.config.ts` (якщо його немає) або просто перевір, щоб посилання в Header вели на існуючі ID, наприклад `/projects/1`, `/projects/2`.
