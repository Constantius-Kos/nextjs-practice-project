# 📌 Урок 9: fetch() та Кешування (Data Fetching)

## 🎯 Мета
- Навчитися отримувати дані в Server Components.
- Зрозуміти, як Next.js кешує запити за замовчуванням.
- Дізнатися про стратегії ревалідації (оновлення) даних.
- Познайомитися з новинкою Next.js 16 — директивою `"use cache"`.

---

## 📖 Теорія

### 1. Data Fetching у Server Components
Найбільша перевага Server Components — ти можеш робити функцію компонента асинхронною (`async`) і використовувати `await fetch()` прямо всередині.

**Більше ніяких `useEffect` для отримання початкових даних!**

```tsx
async function Page() {
  const response = await fetch('https://api.example.com/posts');
  const data = await response.json();

  return (
    <div>
      {data.map(post => <h2 key={post.id}>{post.title}</h2>)}
    </div>
  );
}
```

### 2. Як працює кеш у Next.js
За замовчуванням Next.js **дуже агресивно кешує** всі запити `fetch()`. Якщо ти зробив запит один раз, Next.js запам'ятає результат і при наступному заході на сторінку видасть його миттєво, не звертаючись до API знову.

### 3. Ревалідація (Оновлення даних)
Якщо дані в API часто змінюються, нам треба сказати Next.js: "Оновлюй цей кеш кожні X секунд".

```tsx
// Оновлювати кеш кожні 3600 секунд (1 година)
const response = await fetch('...', { next: { revalidate: 3600 } });
```

### 4. Директива `"use cache"` (Next.js 16)
Це нова експериментальна (але дуже потужна) функція. Вона дозволяє кешувати не просто один запит `fetch`, а результат цілої асинхронної функції.

```tsx
async function getPosts() {
  'use cache'; // Кешуємо результат цієї функції
  return await db.posts.findMany();
}
```

## ✍️ Практика

### Задача 1: Список проектів з "зовнішнього" джерела
Давай імітуємо роботу з реальним API. Ми створимо JSON-файл, який буде нашим "джерелом" даних, і спробуємо його викачати через `fetch`.

**Кроки:**
1. Створи в корені `practice-project` папку `data` і в ній файл `projects.json` з масивом проектів (id, title, description).
2. Онови сторінку `app/projects/page.tsx`. Зроби її асинхронною.
3. Замість статичного списку, отримай дані через `fetch` (можеш вказати шлях до свого JSON-файлу через повний URL, наприклад `http://localhost:3000/data/projects.json`, або просто імітувати асинхронний запит).
4. Виведи проекти циклом `.map()`.
