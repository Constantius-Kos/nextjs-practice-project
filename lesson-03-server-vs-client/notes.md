## 💡 Ключові інсайти

> (Записуй «а-га!» моменти тут)
'use client' — це межа, яка тягне JavaScript до браузера. Navbar сам по собі є SC, отже його код до браузера не потрапляє. Але оскільки Navbar рендерить LoginButton (CC) — браузер отримає JS тільки для LoginButton.
