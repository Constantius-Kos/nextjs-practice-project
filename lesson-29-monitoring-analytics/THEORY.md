# Урок 29: Моніторинг та Аналітика — Очі твого проекту

Коли твій проект на Vercel, він виходить у великий світ. Моніторинг допомагає зрозуміти, чи добре йому там ведеться.

## 1. Навіщо це треба?
Без моніторингу ти сліпий. Ти не знаєш:
*   Чи не занадто повільно відкривається сторінка у юзерів з повільним інтернетом?
*   На якій кнопці юзери найчастіше "відвалюються"?
*   Яка помилка виникає тільки в Safari на iPhone?

## 2. Core Web Vitals (CWV)
Google оцінює твій сайт за трьома головними показниками:
1. **LCP (Largest Contentful Paint)** — Швидкість завантаження: Як швидко з'являється найбільший елемент (картинка/текст). *Ціль: < 2.5с.*
2. **CLS (Cumulative Layout Shift)** — Стабільність: Чи не "стрибає" контент, коли довантажуються картинки. *Ціль: < 0.1.*
3. **INP (Interaction to Next Paint)** — Чуйність: Як швидко сайт реагує на клік. *Ціль: < 200мс.*

## 3. Інструменти у Next.js 16

### Vercel Speed Insights
Це вбудований інструмент Vercel. Він збирає дані від **реальних юзерів** (RUM — Real User Monitoring). 
*   **Плюс:** Ти бачиш не синтетичний тест свого комп'ютера, а реальну картину світу.

### Vercel Analytics
Показує кількість відвідувачів, сторінки входу, типи пристроїв та країни.

### Error Tracking (Sentry / Logtail)
Якщо в коді станеться помилка (`ReferenceError` тощо), Sentry надішле тобі листа з повним описом: де, у кого і на якому рядку це сталось.

## 4. Як додати аналітику в Next.js 16?
Замість того, щоб копіювати брудні скрипти в `<head>`, Next.js пропонує готові компоненти:

```tsx
import { Analytics } from "@vercel/analytics/react"
import { SpeedInsights } from "@vercel/speed-insights/next"

export default function Layout({ children }) {
  return (
    <html>
      <body>
        {children}
        <Analytics />
        <SpeedInsights />
      </body>
    </html>
  )
}
```

### 🔑 Словничок термінів:
*   **Real User Monitoring (RUM)** — збір даних про продуктивність безпосередньо у реальних відвідувачів.
*   **Hydration Time** — час, за який статична HTML сторінка стає інтерактивною завдяки React.
*   **Bounce Rate** — відсоток юзерів, які пішли з сайту, подивившись лише одну сторінку.
