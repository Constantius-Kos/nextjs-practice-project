# Практика: Урок 29 — Підключаємо "Очі"

Сьогодні ми зробимо наш деплой на Vercel професійним.

## Задача 1: Встановлення пакетів
Тобі потрібно встановити два офіційні пакети від Vercel:
`@vercel/analytics` та `@vercel/speed-insights`.

## Задача 2: Інтеграція в Root Layout
1. Відкрий `app/layout.tsx`.
2. Імпортуй компоненти `Analytics` та `SpeedInsights`.
3. Додай їх у самий низ `<body>`, щоб вони почали збирати дані.

## Задача 3: Перевірка на Dashboard
1. Після того, як запушиш код у GitHub і Vercel зробить перезбірку (redeploy).
2. Зайди у свій проект на сайті **vercel.com**.
3. Знайди вкладки **Analytics** та **Speed Insights**.
4. **Важливо:** Дані з'являться не миттєво, а після того, як ти сам пройдешся по сайту (або попросиш друзів).

## Задача 4: Челлендж — Навмисна помилка
1. Створи сторінку або кнопку, яка при кліку викликає помилку: `throw new Error("Test Monitoring Error")`.
2. Подивись, чи з'явиться ця помилка в логах Vercel (вкладка **Logs**) або у Sentry (якщо наважишся підключити).
