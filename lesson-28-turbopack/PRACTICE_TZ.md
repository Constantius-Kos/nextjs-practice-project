# Практика: Урок 28 — Turbopack Speed Test

Сьогодні ми не будемо писати багато коду. Наша мета — відчути різницю в швидкості розробки.

## Задача 1: Порівняння Cold Start
1. Зупини сервер розробки (Ctrl+C).
2. Запусти його звичайним способом: `npm run dev`.
3. Засічи (приблизно), скільки секунд минає від натискання Enter до моменту, коли в терміналі з'явиться `Ready in ...ms`.
4. Тепер спробуй вимкнути Turbo (якщо воно раптом увімкнено за замовчуванням у твоїй версії) або навпаки — переконайся, що прапорець `--turbo` присутній.

## Задача 2: Екстремальний HMR
1. Відкрий будь-яку сторінку (наприклад, `/detect`).
2. Постав вікно браузера і вікно редактора поруч.
3. Зміни колір тексту або заголовок і натисни `Ctrl+S`.
4. Спробуй вловити оком момент оновлення. З Turbopack це має бути "миттєво".

## Задача 3: Дослідження "несумісності" (Challenge)
Turbopack іноді конфліктує з дуже специфічними налаштуваннями Webpack.
1. Подивись у свій `next.config.ts`. 
2. Чи є там щось, що стосується `webpack: (config) => { ... }`?
3. Якщо ні — тобі пощастило! Якщо так — знайди інформацію, чи підтримує Turbopack ці налаштування зараз.
