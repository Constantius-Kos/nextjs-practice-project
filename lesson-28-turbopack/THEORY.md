# Урок 28: Turbopack — Двигун твого проекту

## 1. Що таке бандлер (Bundler)?
Уяви, що твій код — це конструктор LEGO. У тебе є сотні дрібних деталей (файлів `.tsx`, `.ts`, `.css`). 
Браузер — це дитина, яка хоче гратися вже зібраною машинкою. 

**Бандлер (Webpack, Vite, Turbopack)** — це робот, який:
1. **Збирає докупи:** Знаходить всі імпорти та залежності.
2. **Перекладає:** Перетворює TypeScript у JavaScript, щоб браузер його зрозумів.
3. **Оптимізує:** Стискає код, видаляє зайві пробіли (minification).
4. **Видаляє сміття:** Викидає код, який ти імпортував, але не використовуєш (Tree Shaking).

## 2. Чому Webpack став повільним?
**Webpack** був королем 10 років. Він написаний на **JavaScript**. 
JavaScript — чудова мова, але коли у тебе в проекті 5000 компонентів, Webpack починає "задихатися". Кожна зміна файлу змушує його перераховувати величезні графи залежностей.

## 3. Turbopack: На надшвидких швидкостях (Rust)
**Turbopack** — це новий бандлер від творців Next.js, написаний на **Rust**. 
Чому це важливо?
*   **Rust vs JS:** Rust компілюється в машинний код. Це як порівнювати швидкість людини, яка читає інструкцію (JS), з роботом, у якого ця інструкція вшита в залізо (Rust).
*   **Incremental Computation:** Головна фішка Turbopack. Він не перераховує все дерево щоразу. Він кешує результат кожної маленької функції. Якщо ти змінив колір однієї кнопки, Turbopack перерахує ТІЛЬКИ цю кнопку.

## 4. Що таке HMR (Hot Module Replacement)?
Це те, що ти бачиш щодня: ти зберіг файл, і сторінка в браузері оновилася миттєво БЕЗ повного перезавантаження.
Turbopack робить HMR настільки швидким, що затримка стає непомітною для людського ока (менше 10мс).

## 5. Turbopack у Next.js 16
У Next.js 16 Turbopack увімкнено за замовчуванням для режиму розробки. Коли ти пишеш `npm run dev`, ти насправді запускаєш:
`next dev --turbo`

### Чому він ще "Experimental" для збірки (build)?
Turbopack ще не підтримує абсолютно всі плагіни Webpack. Тому для `npm run build` (production) Next.js поки що використовує Webpack, щоб забезпечити 100% стабільність. Але в розробці — тільки Turbo!

---

### 🔑 Словничок термінів:
*   **Bundling** — процес збирання файлів у один/декілька пакетів.
*   **Cold Start** — перший запуск сервера розробки (коли ще немає кешу).
*   **HMR** — миттєве оновлення коду в браузері при збереженні.
*   **Dependency Graph** — карта того, який файл що імпортує.
