# English: Lesson 28 — Turbopack & Bundling

| Word | Translation | Context in Next.js |
|------|-------------|--------------------|
| **Bundler** | Бандлер / Пакувальник | Інструмент для збірки проекту (Turbopack, Webpack). |
| **Dependency** | Залежність | Бібліотека або файл, який потрібен для роботи коду. |
| **Out of the box** | "З коробки" | Фіча, яка працює одразу без налаштувань. |
| **Incremental** | Інкрементальний (поступовий) | Обробка тільки тих частин, що змінилися. |
| **Overhead** | Накладні витрати | Зайві ресурси (час/пам'ять), що витрачаються на процес. |
| **Cold start** | Холодний запуск | Перший запуск системи без попередньо збережених даних. |
