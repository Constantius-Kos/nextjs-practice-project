## 📖 Теорія

### 1. Що таке Streaming?
Раніше (у традиційному SSR) сервер мав дочекатися завершення **всіх** запитів до даних, перш ніж відправити HTML користувачу. Якщо один запит повільний — вся сторінка "висить".

**Streaming** дозволяє розбити сторінку на частини (chunks). Сервер одразу відправляє готові статичні частини (наприклад, Header, Sidebar), а динамічні частини (список товарів, коментарі) "довантажуються" по мірі готовності.

### 2. Автоматичне завантаження: `loading.tsx`
Спеціальний файл `loading.tsx` у папці сегмента маршруту автоматично обертає твою сторінку (`page.tsx`) у React Suspense.

**Як це працює:**
1. Next.js бачить `loading.tsx`.
2. Поки дані в `page.tsx` завантажуються (наприклад, через `fetch`), користувач бачить вміст з `loading.tsx`.
3. Як тільки дані готові, контент замінюється автоматично.

### 3. Компонент `<Suspense>` (Гранулярне завантаження)
Якщо ти не хочеш "ховати" всю сторінку під один завантажувач, ти можеш обернути конкретний компонент у `<Suspense fallback={<Loader />}>`.

Це ідеально, якщо у тебе на сторінці є:
- Швидкий текст (заголовок).
- Повільний список (дані з API).

## 💡 Приклади

### Приклад loading.tsx (у тій же папці що і page.tsx):
```tsx
export default function Loading() {
  return <p className="animate-pulse">Завантаження даних...</p>
}
```

## ✍️ Практика (Інтеграція в проект)

Тепер давай застосуємо це до твого `practice-project`.

### Задача 1: Глобальний лоадер для проектів
1. У папці `app/(main)/projects/` створи файл `loading.tsx`.
2. Напиши там простий компонент, який виводить "Завантажуємо проекти...".
3. Щоб побачити результат (адже локальний `fetch` дуже швидкий), додай штучну затримку в `projects/page.tsx`:
   `await new Promise(resolve => setTimeout(resolve, 2000))`

### Задача 2: Гранулярний Suspense
1. Видали `loading.tsx`.
2. Розділи сторінку `projects/page.tsx` на два компоненти: заголовок (`<h1>`) та список проектів (окремий серверний компонент).
3. Оберни тільки список проектів у `<Suspense fallback={...}>`.
4. Переконайся, що заголовок з'являється миттєво, а список — через 2 секунди.
