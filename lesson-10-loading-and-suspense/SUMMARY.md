# 📋 Резюме уроку 10: Streaming UI та loading.tsx

### 1. Концепція Streaming (Потокова передача)
- Традиційний підхід: чекаємо 3 секунди на дані -> віддаємо всю сторінку.
- **Streaming**: Одразу віддаємо Header та Sidebar -> замість контента показуємо "лоадер" -> дані готові -> "вкидаємо" контент в HTML.
- Сторінка відчувається для користувача як миттєво завантажена.

### 2. loading.tsx: Автоматичний режим
- Просто поклади файл `loading.tsx` поруч з `page.tsx`. Next.js автоматично оберне твою сторінку в React `Suspense`.
- Поки сторінка робить `fetch`, показується контент з `loading.tsx`. Будь-які зміни відбуваються без перезавантаження.

### 3. Компонент `<Suspense>` (Гранулярність)
- Якщо ти не хочеш ховати всю сторінку під один завантажувач, ти можеш загорнути **окремий повільний компонент**:
  ```tsx
  <Suspense fallback={<Skeleton />}>
     <SlowComponent />
  </Suspense>
  ```
- Тепер заголовок сторінки з'явиться миттєво, а список товарів довантажиться пізніше.

### 4. Skeletouns (Скелетони)
- Найкраща практика для `loading.tsx` — це макет, який візуально нагадує майбутній контент (сірі прямокутники замість тексту). Це заспокоює користувача та покращує UX.

### 5. UX показники
- Стрімінг допомагає покращити **TTFB** (Time To First Byte) та **LCP** (Largest Contentful Paint), що позитивно впливає на SEO та загальне сприйняття швидкості сайту.
