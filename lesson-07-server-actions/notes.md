# 📝 Нотатки Уроку 8: Server Actions

### Запитання та відповіді

**Запитання:** Як і де використовується `description` у метаданих?
**Відповідь:** 
1. **Google/Пошук:** Це той самий текст-анонс, який відображається під назвою сайту в результатах пошуку.
2. **Соцмережі:** Використовується для створення прев'ю (карток), коли ти ділишся посиланням у Telegram, Slack або Facebook.
3. **SEO:** Допомагає залучити користувача клікнути на сайт (підвищує CTR).
Next.js автоматично рендерить його як `<meta name="description" content="...">` у секції `<head>`.

**Запитання:** А що впливає на позицію в рейтингу гугла?
**Відповідь:** 
1. **Title:** Найсильніший тег. Має містити ключові слова.
2. **Швидкість (Core Web Vitals):** Наскільки швидко сайт стає інтерактивним. Next.js тут лідер.
3. **Семантика:** Правильне використання `<h1>`, `<h2>`, `<article>` замість просто куп `<div>`.
4. **Контент:** Наскільки інформація корисна та унікальна.
5. **Мобільність:** Наскільки зручно користуватися з телефона.
6. **Посилання:** Чи посилаються на твій сайт інші авторитетні ресурси.

**Запитання:** Як властивості метаданих в Next.js виглядають у звичайному HTML?
**Відповідь:** Кожна властивість перетворюється на окремий тег у `<head>`.
- `title` → `<title>...</title>`
- `description` → `<meta name="description" content="..." />`
- `openGraph` → ціла пачка тегів `<meta property="og:..." content="..." />`
Next.js автоматизує цей процес, об'єднує метадані з різних рівнів (layout + page) та забезпечує правильність написання тегів.

### 📋 Шпаргалка по властивостях метаданих

| Властивість | Для чого потрібна | Приклад |
| :--- | :--- | :--- |
| **title** | Заголовок вкладки та посилання в Google | `title: 'Головна'` |
| **description** | Опис під посиланням у Google | `description: 'Найкращий софт...'` |
| **keywords** | Ключові слова (малоактуально) | `keywords: ['poker', 'soft']` |
| **openGraph** | Прев'ю у Telegram / Facebook | `openGraph: { title: '...', images: [...] }` |
| **twitter** | Специфічні прев'ю для Twitter (X) | `twitter: { card: 'summary_large_image' }` |
| **robots** | Дозвіл/Заборона індексації | `robots: { index: true, follow: true }` |
| **icons** | Іконка сайту (Favicon) | `icons: { icon: '/favicon.ico' }` |
| **authors** | Автор контенту | `authors: [{ name: 'Ivan', url: '...' }]` |
| **metadataBase** | Базовий URL для всіх картинок | `metadataBase: new URL('https://site.com')` |

**Запитання:** Що таке `metadataBase` і навіщо воно?
**Відповідь:** Це "корінь" твого сайту. Соцмережі (TG, FB) потребують повних посилань на картинки (з `https://...`). `metadataBase` дозволяє тобі писати короткі шляхи (наприклад, `/img.png`), а Next.js сам доклеїть до них твій домен, перетворюючи їх на повні адреси.

**Запитання:** Що таке `index` та `follow` у налаштуваннях `robots`?
**Відповідь:** 
- **Index:** "Чи показувати сторінку в результатах пошуку?" (`true` — так, `false` — приховати).
- **Follow:** "Чи довіряти посиланням на цій сторінці?" (`true` — дозволити роботу переходити далі за посиланнями, `false` — не переходити).
Зазвичай для публічних сторінок ставлять обидві властивості в `true`.

**Запитання:** Який об'єкт автоматично приходить у Server Action при сабміті форми?
**Відповідь:** Об'єкт **`FormData`**. З нього можна дістати дані за допомогою методу `.get('назва_поля')`.

**Запитання:** Чи можна використовувати Server Actions у Client Components?
**Відповідь:** Так, але їх треба виносити в окремий файл з директивою `'use server'` на початку файлу, а потім імпортувати в клієнтський компонент. Писати `'use server'` прямо всередині `'use client'` файлу не можна.

**Запитання:** Як зробити редірект після виконання Server Action?
**Відповідь:** Потрібно використовувати функцію `redirect` з пакету `next/navigation`. Вона викликається прямо всередині серверної функції. Використовувати `useRouter` в екшені не можна, бо це клієнтський хук.
```ts
import { redirect, RedirectType } from 'next/navigation'
export async function myAction() {
  // За замовчуванням працює як push
  redirect('/success') 
  
  // Якщо треба як replace (без історії):
  redirect('/success', RedirectType.replace)
}
```
