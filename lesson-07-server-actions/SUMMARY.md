# 📋 Резюме уроку 7: Server Actions

### 1. Що таке Server Actions?
- Це **асинхронні функції**, які виконуються на сервері, але викликаються безпосередньо з клієнтської сторони (наприклад, при натисканні кнопки або сабміті форми).
- Більше не потрібно писати `fetch('/api/...)` — ти просто викликаєш функцію.

### 2. Директива `'use server'`
- Щоб функція стала екшеном, на самому початку її файлу (найкраща практика) або всередині самої функції має бути рядок `'use server'`.
- Це вказує Next.js, що цей код — публічна крапка входу для виклику з браузера.

### 3. Використання у формах
- Замість обробки завантаження вручну через стейти, ми передаємо функцію в атрибут **`action={myAction}`** форми.
- Браузер автоматично збирає всі дані в об'єкт `FormData`.

### 4. useFormStatus — стан завантаження
- Хук повертає об'єкт `{ pending: true/false }`, що дозволяє легко вимикати кнопку (disabled) або показувати лоадер, поки сервер обробляє дані.
- **Важливо**: Компонент з цим хуком має бути **всередині** `<form>`.

### 5. Type Safety (Типізація)
- Оскільки це звичайна TypeScript-функція, ти отримуєш повну перевірку типів аргументів. Це набагато надійніше, ніж передавати JSON через API-роути.
