# 🇬🇧 English for Next.js 16 (Lesson 13)

| Term | Transcription | Translation | Context in Next.js |
| :--- | :--- | :--- | :--- |
| **Caching** | /ˈkæʃ.ɪŋ/ | Кешування | Збереження результату запиту для повторного використання. |
| **Directive** | /daɪˈrek.tɪv/ | Директива | Спеціальна вказівка для компілятора (як `"use client"`). |
| **Serialization** | /ˌsɪə.ri.ə.laɪˈzeɪ.ʃən/ | Серіалізація | Перетворення об'єкта в формат, який можна зберегти/передати (наприклад, JSON). |
| **Granular** | /ˈɡræn.jə.lə/ | Детальний / Гранулярний | Коли ми можемо керувати кешем на рівні маленьких шматочків коду. |
| **Explict** | /ɪkˈsplɪs.ɪt/ | Явний | Коли ми чітко вказуємо намір у коді. |
| **Cache Hit** | /kæʃ hɪt/ | Влучання в кеш | Ситуація, коли дані знайдено в кеші. |
| **Cache Miss** | /kæʃ mɪs/ | Промах повз кеш | Ситуація, коли даних в кеші немає і треба йти до БД. |
| **Revalidation** | /ˌriː.væl.ɪˈdeɪ.ʃən/ | Ревалідація (оновлення) | Процес перевірки чи оновлення застарілих даних у кеші. |
| **Stale** | /steɪl/ | Застарілий | Дані, які все ще в кеші, але в базі вони вже інші. |
| **Invalidation** | /ɪnˌvæl.ɪˈdeɪ.ʃən/ | Анулювання / Очищення | Процес видалення застарілих даних з кешу. |
