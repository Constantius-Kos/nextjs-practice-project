## 🎯 Ключові концепції для засвоєння

### Топ-5 «а-га» моментів Next.js 16:
1. **Server Components** — компоненти виконуються на сервері, не в браузері
2. **`'use client'`** — це межа, а не просто директива
3. **`"use cache"`** — нова єдина модель кешування замість PPR
4. **Server Actions** — форми без API routes
5. **Turbopack** — Rust-бандлер, вбудований за замовчуванням
