# English for Middleware (Lesson 24)

| Term | Transcription | Translation | Context in Next.js |
|------|---------------|-------------|--------------------|
| **Middleware** | /ˈmɪdl.weər/ | Проміжне ПЗ / Перехоплювач | Код, що виконується між запитом та відповіддю. |
| **Matcher** | /ˈmætʃ.ər/ | Узгоджувач / Фільтр | Правило для визначення шляхів, де працює middleware. |
| **Redirect** | /ˌriː.daɪˈrekt/ | Перенаправлення | Зміна адреси з відповіддю 301/302. |
| **Rewrite** | /ˌriːˈraɪt/ | Перезапис (маскування) | Підміна контенту без зміни URL в браузері. |
| **Edge Runtime** | /edʒ ˈrʌn.taɪm/ | "Крайне" середовище | Легкий сервер для швидкого виконання коду ближче до юзера. |
| **Header** | /ˈhed.ər/ | Заголовок | Метадані запиту або відповіді (н-ад: Content-Type). |
| **Request** | /rɪˈkwest/ | Запит | Те, що приходить від браузера до сервера. |
| **Response** | /rɪˈspɒns/ | Відповідь | Те, що сервер повертає у браузер. |
