# Практичне завдання до Уроку 24: Middleware 🛡️

## Мета
Навчитися перехоплювати запити, захищати сторінки та керувати редіректами на рівні всього додатка.

---

## Task 1: Створення Middleware
1.  Створи файл `middleware.ts` у корені папки `practice-project` (поруч з `app/`).
2.  Напиши базову функцію, яка просто виводить `console.log("Middleware works!")` на кожен запит.
3.  Перевір термінал — чи бачиш ти лог при кліках по сайту?

## Task 2: Захист роута /dashboard
1.  Налаштуй `matcher` так, щоб Middleware спрацьовував тільки для `/dashboard` та його підпапок.
2.  Перевір наявність куки або сесії.
3.  Якщо користувач не авторизований — зроби `NextResponse.redirect` на головну сторінку `/`.

## Task 3: Маніпуляція заголовками (Headers)
1.  Додай кастомний заголовок `x-middleware-applied: true` до запиту.
2.  У компоненті `dashboard/page.tsx` спробуй прочитати цей заголовок через `headers()` з `next/headers`.

## Task 4: Редірект за умовою (Bot Detection / Maintenance)
1.  Спробуй визначити "бота" за `user-agent` в заголовках.
2.  Якщо це бот (або просто імітуй умову) — зроби редірект на спеціальну сторінку `/maintenance`.

---

## 🛠️ Технічні вимоги:
- Використовуй тільки `NextResponse` та `NextRequest`.
- Пам'ятай про Edge Runtime (ніяких `prisma` або `fs` всередині middleware!).
