# 📋 Резюме уроку 1: Що таке Next.js 16 і App Router

### 1. Що таке Next.js?
- **React Framework**: Це повноцінне рішення для сайтів, яке включає маршрутизацію, серверний рендеринг (SSR), оптимізацію зображень та готові API-роути.
- **Next.js 16**: Нова версія, що використовує Turbopack (бандлер на Rust), інтегрує React 19.2 та пропонує нову модель кешування `"use cache"`.

### 2. App Router — нова філософія
- **Папка `/app`**: Тепер це центр додатку. Всі компоненти всередині за замовчуванням є **Server Components**.
- **Порівняння**: Pages Router (застарілий) працював тільки на клієнті, App Router робить ставку на серверні потужності.

### 3. Server Components (Серверні компоненти)
- **Де виконуються?** Виключно на сервері. У браузер клієнта JS-код компонента не потрапляє.
- **Плюси**: Швидкість, безпека (можна писати SQL-запити прямо в коді), менший об'єм завантажуваних даних.
- **Async**: Можуть бути асинхронними (`async function`), що дозволяє робити `await` прямо всередині.

### 4. Client Components (`'use client'`)
- **Коли потрібні?** Тільки якщо компоненту потрібна інтерактивність (кнопки, форми), стейт (`useState`) або браузерні API (`window`, `localStorage`).
- **Директива**: Рядок `'use client'` на самому початку файлу перетворює його на клієнтський.

### 5. Структура проєкту
- `layout.tsx`: Спільна обгортка для всіх сторінок (Header, Footer).
- `page.tsx`: Конкретна сторінка маршруту.
- `loading.tsx` та `error.tsx`: Вбудована обробка станів завантаження та збоїв.
