# 📋 Резюме уроку 9: Route Groups (Групування маршрутів)

### 1. Що таке Route Groups?
- Це папки, назва яких взята в круглі дужки: **`(group-name)`**.
- Next.js повністю **ігнорує** ці папки при створенні посилань (URL).

### 2. Організація коду
- Дозволяють логічно групувати файли за темами (наприклад, `(auth)`, `(admin)`, `(marketing)`), не роздуваючи корінь папки `app/`. 
- При переході на `/login` користувач не бачить назву групи `(auth)` в адресному рядку.

### 3. Розділення Layout-ів
- Це головна причина використовувати групи. Ти можеш створити:
  - `(admin)/layout.tsx` — з боковим меню адміна.
  - `(public)/layout.tsx` — з яскравим хедером і футером.
- Сторінки всередині групи отримають тільки «свій» макет.

### 4. Кілька Root Layouts
- Використовуючи Route Groups, ти можеш створити **кілька незалежних Root Layouts**, кожен з яких має власний тег `<html>` та `<body>`.
- Це корисно, якщо маркетингова сторінка має зовсім інші шрифти та стилі, ніж основний додаток.

### 5. Спільні провайдери
- Групи — ідеальне місце, щоб обернути частину сайту (наприклад, всі сторінки дашборду) спільним React Context або банером повідомлень, не зачіпаючи решту сайту.
