# 🇬🇧 English for Developers: Lesson 15

| Термін | Транскрипція | Переклад | Опис |
| :--- | :--- | :--- | :--- |
| **Lifecycle** | /ˈlaɪfˌsaɪkl/ | Життєвий цикл | Час від створення запису в кеші до його видалення. |
| **Duration** | /djʊˈreɪʃn/ | Тривалість | Певний проміжок часу (наприклад, 60 секунд). |
| **Stale** | /steɪl/ | Несвіжий / Старий | Дані, час життя яких вийшов, але вони все ще в кеші. |
| **Stale-while-revalidate** | | Старе під час оновлення | Процес показу старих даних, поки нові завантажуються. |
| **Immutable** | /ɪˈmjuːtəbl/ | Незмінний | Дані, які ніколи не змінюються (кеш навічно). |
| **Granularity** | /ˌɡrænjuˈlærəti/ | Деталізація | Можливість налаштувати кеш для кожного маленького блоку окремо. |

---

### Приклади використання:
- *"The **duration** of this cache entry is set to one hour."*
- *"We need to reduce the **granularity** of our revalidation logic."*
- *"Don't show **stale** data to the user if the price is critical."*
