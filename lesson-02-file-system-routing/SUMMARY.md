# 📋 Резюме уроку 2: Файлова система як маршрутизація

### 1. Маршрутизація через папки
- В Next.js **Папка = URL-сегмент**. Структура папок в `app/` автоматично будує дерево посилань сайту.
- **Публічність**: Маршрут стає доступним лише тоді, коли в папці є файл `page.tsx`.

### 2. Зарезервовані імена файлів
Кожне ім'я має свою магічну роль:
- **`page.tsx`**: Головний контент сторінки.
- **`layout.tsx`**: Обгортка-каркас. Зберігає стан при переході між сторінками.
- **`loading.tsx`**: Скелетон, який показується автоматично під час завантаження.
- **`error.tsx`**: Обробник помилок (має бути `'use client'`).
- **`not-found.tsx`**: Кастомна сторінка 404.

### 3. Layout: Магія обгортки
- **Стабільність**: При переході з `/about` на `/contacts` `RootLayout` не перерендериться. Це ідеально для Sidebars та Navbars.
- **Вкладеність**: Ти можеш створювати локальні лейаути для окремих розділів (наприклад, `app/dashboard/layout.tsx`), які вкладатимуться в кореневий.

### 4. Автоматизація з loading.tsx
- Коли ти додаєш цей файл, Next.js автоматично загортає твою сторінку в React `Suspense`. 
- Це дозволяє сайту "стрімити" (Streaming) контент — шапка з'являється одразу, а контент "доїжджає", коли браузер отримає дані.

### 5. error.tsx — твій щит
- Цей компонент перехоплює будь-які помилки в його сегменті.
- Вимагає `'use client'`, бо містить пропс `reset`, який дозволяє користувачу спробувати завантажити сторінку ще раз без F5.
