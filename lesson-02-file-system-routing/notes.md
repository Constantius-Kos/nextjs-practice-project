### Задача 3: Знайди помилку

> (Заповни тут)

```tsx
// app/blog/error.tsx
export default function Error({ reset }: { reset: () => void }) {
  return <button onClick={reset}>Retry</button>
}
```

Що тут неправильно і чому?
немає флага клієнтського компонента, та мені не зрозуміло чому тайп поверненого компонентом визначений як reset якщо він повертає jsx?

**✅ Відповідь ментора:**
`reset: () => void` — це НЕ тип того, що повертає компонент.
Це тип ПРОПСА `reset` — функція, яка нічого не повертає (void).

```tsx
// Розбираємо сигнатуру:
function Error({
  error,   // проп типу Error (вбудований JS тип)
  reset,   // проп типу () => void (функція без повернення)
}: {
  error: Error        // ← тип пропса error
  reset: () => void   // ← тип пропса reset: "функція, що повертає нічого"
}) {
  return <button onClick={reset}>Retry</button>
  // компонент повертає JSX — це його власний тип (React.ReactNode)
}
```

`() => void` читається як: "функція без аргументів, яка нічого не повертає".
Next.js сам передає цю функцію — вона скидає стан помилки і перерендеровує сторінку.
