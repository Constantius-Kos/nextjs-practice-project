# 📋 Резюме уроку 5: Навігація (Link та useRouter)

### 1. Чому `<Link>` кращий за `<a>`?
- **SPA Experience**: `<Link>` перехоплює клік і підміняє контент без повного перезавантаження сторінки. Це працює миттєво.
- **Prefetching**: Next.js автоматично завантажує код сторінок за посиланнями, коли вони з'являються у в'юпорті (зоні видимості).

### 2. useRouter — програмна навігація
- Хук `useRouter` використовується в **Client Components**, коли треба змінити адресу кодом (наприклад, після натискання на кнопку або відправки даних).
- Потрібно імпортувати саме з `next/navigation` (не з `next/router`).

### 3. Основні методи роутера
- **`push('/path')`**: Новий перехід, який зберігається в історії браузера.
- **`replace('/path')`**: Замінює поточну сторінку (не можна повернутися назад, корисно для сторінок успіху після оплати чи форм).
- **`back()`**: Аналог кнопки "Назад" у браузері.

### 4. Серверна навігація: `redirect()`
- Якщо тобі треба перенаправити користувача з **Server Component** або **Server Action**, використовуй функцію `redirect('/new-path')`.
- Код після `redirect()` ніколи не виконується, бо функція викликає "ексепшн", який Next.js обробляє внутрішньо.

### 5. Активні посилання
- Для підсвічування поточного пункту меню використовуй хук **`usePathname()`**. Він повертає поточний шлях (наприклад, `/blog`), який можна порівняти з `href` посилання.
