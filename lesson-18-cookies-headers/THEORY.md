# 📖 Теорія Уроку 18: Cookies та Headers у Server Components

У Next.js 16 ми можемо отримувати доступ до даних запиту (хто заходить на сайт, які у нього налаштування, чи залогінений він) прямо всередині серверних компонентів. Для цього використовуються дві магічні функції: `headers()` та `cookies()`.

---

### 1. 📥 Функція `headers()`

Вона дозволяє дізнатися системну інформацію про браузер та пристрій користувача.

```typescript
import { headers } from 'next/headers';

export default async function Page() {
  const headersList = await headers();
  const userAgent = headersList.get('user-agent');
  
  return <div>Твій браузер: {userAgent}</div>;
}
```

**Навіщо це потрібно?**
*   Дізнатися мову користувача (`accept-language`).
*   Визначити тип пристрою (мобільний чи десктоп).
*   Перевірити, чи запит прийшов через наш Проксі.

---

### 2. 🍪 Функція `cookies()`

Куки — це маленькі текстові файли, які зберігаються в браузері користувача. Це головний спосіб "впізнати" користувача.

**Читання кук:**
```typescript
import { cookies } from 'next/headers';

export default async function Page() {
  const cookieStore = await cookies();
  const theme = cookieStore.get('theme'); // 'dark' або 'light'
  
  return <div className={theme?.value}>Вітаємо!</div>;
}
```

---

### ⚠️ Важливе правило (Dynamic Rendering)

Як тільки ти викликаєш `headers()` або `cookies()`, твоя сторінка автоматично стає **Динамічною**.
*   **Чому?** Бо сервер не може знати заздалегідь, які куки будуть у конкретної людини. Він має згенерувати сторінку саме в момент заходження (Request Time).
*   Це означає, що така сторінка **не буде закешована** як статичний HTML.

---

### 3. ✍️ Встановлення Cookies (Server Actions)

Як ми вже знаємо, Server Components можуть тільки читати. Для запису кук нам потрібен "активний" код на сервері — **Server Action**.

```typescript
import { cookies } from 'next/headers';

async function updateTheme(newTheme: string) {
  'use server'; // Магічна директива
  const cookieStore = await cookies();
  cookieStore.set('theme', newTheme);
}
```

**Чому це круто?**
Коли ти викликаєш таку функцію, Next.js автоматично зробить POST-запит на сервер, оновить куку і **автоматично оновить сторінку**, щоб ти побачив зміни без зайвого коду `window.location.reload()`.
