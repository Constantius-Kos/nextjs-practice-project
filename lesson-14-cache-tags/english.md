# 🇬🇧 English Terms (Lesson 14)

| Term | Transcription | Translation | Context in Next.js |
| :--- | :--- | :--- | :--- |
| **Revalidate** | /ˌriːˈvæl.ɪ.deɪt/ | Перепровірити / Оновити | Процес очищення кешу та отримання нових даних. |
| **Tag** | /tæɡ/ | Тег / Мітка | Стрінгерний ідентифікатор для групи закешованих даних. |
| **On-demand** | /ˌɒn dɪˈmɑːnd/ | На вимогу | Оновлення кешу тоді, коли це потрібно нам, а не за розкладом. |
| **Purge** | /pɜːdʒ/ | Очистити / Видалити | Процес повного видалення застарілих даних з кешу. |
| **Invalidation** | /ɪnˌvæl.ɪˈdeɪ.ʃən/ | Інвалідація / Скасування | Оголошення закешованих даних застарілими. |
| **Stale-While-Revalidate** | /steɪl waɪl ˌriːˈvæl.ɪ.deɪt/ | Старе під час оновлення | Стратегія "поки оновлюється — показуй старе". |
| **Sticky state** | /ˈstɪk.i steɪt/ | Липкий стан | Стійкий стан (наприклад, помилка, яку треба скидати вручну). |
| **Bridge** | /brɪdʒ/ | Міст / Зв'язок | Механізм зв'язку між клієнтськими та серверними діями. |
| **Lazy Loading** | /ˈleɪ.zi ˈləʊ.dɪŋ/ | Ледаче завантаження | Отримання даних лише тоді, коли вони реально знадобилися. |
| **Cache Miss** | /kæʃ mɪs/ | Промах кешу | Стан, коли потрібні дані відсутні в кеші. |
