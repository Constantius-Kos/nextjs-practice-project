# 📖 Теорія Уроку 17: Proxy Pattern (proxy.ts)

### 🧐 Що таке Proxy? (Пояснення для новачків)

Уяви ситуацію: ти хочеш замовити таємний подарунок, але не хочеш, щоб продавець знав твою домашню адресу чи бачив твоє обличчя. 

**Як це працює без проксі:**
Ти напряму йдеш до продавця -> Він бачить тебе, твій гаманець і твою адресу.

**Як це працює з проксі:**
1. Ти просиш **кур'єра (Proxy)**: "Сходи в магазин і купи мені це".
2. Кур'єр йде в магазин. Продавець бачить тільки кур'єра.
3. Кур'єр забирає товар і приносить його тобі.

В розробці **Proxy (Проксі)** — це такий самий "посередник" (твій власний сервер), через який твій браузер спілкується з іншими сервісами.

---

У сучасних Next.js додатках ми намагаємось уникати важкого `middleware.ts`, бо він обмежує нас у використанні багатьох бібліотек. Замість цього ми використовуємо **Proxy Pattern** через Route Handlers.

---


### 1. 🛡️ Навіщо потрібен Proxy?

Уяви, що ти використовуєш платний API (наприклад, OpenAI або прогноз погоди).
*   **Проблема:** Якщо ти зробиш `fetch` прямо з браузера (Client Component), твій приватний API-ключ буде видно всім у вкладці Network.
*   **Рішення (Proxy):** 
    1. Клієнт шле запит на Твій сервер (`/api/proxy/weather`).
    2. Твій сервер додає секретний ключ і шле запит на Справжній API.
    3. Твій сервер повертає дані клієнту.
**Результат:** Ключ у безпеці на сервері.

---

### 2. 🔌 Як реалізувати проксі

Ми створюємо файл `app/api/proxy/[...path]/route.ts` (використовуємо catch-all роути, щоб один файл обробляв різні шляхи).

```typescript
// app/api/proxy/route.ts
import { NextRequest, NextResponse } from 'next/server';

export async function GET(req: NextRequest) {
  const targetUrl = "https://api.external.com/data";
  
  const res = await fetch(targetUrl, {
    headers: {
      "Authorization": `Bearer ${process.env.API_KEY}`
    }
  });

  const data = await res.json();
  return NextResponse.json(data);
}
```

---

### 3. 🌐 Переваги перед Middleware
1. **Node.js Runtime:** Можна використовувати будь-які бібліотеки (наприклад, для роботи з зображеннями або PDF).
2. **Кешування:** Проксі-роути можна кешувати через `"use cache"`.
3. **Менше "магії":** Поведінка API роутів більш передбачувана, ніж глобального middleware.

#### Задача 1: Проксі для погоди
Створи `app/api/weather-proxy/route.ts`.
* Він має робити запит на `https://api.open-meteo.com/v1/forecast?latitude=50.45&longitude=30.52&current_weather=true`.
* Додай до відповіді заголовок `X-Proxied-By: MyNextApp`.
* Перевір, чи отримуєш ти дані Києва за адресою `localhost:3000/api/weather-proxy`.

#### Задача 2: Обертка (Wrapper)
Зроби так, щоб твій проксі повертав об'єкт, де оригінальні дані лежать у полі `data`, а також додавався `timestamp`.

#### Задача 3: Безпека
Спробуй перевірити в проксі наявність спеціального заголовка `x-proxy-auth`. Якщо його немає — повертай помилку 401.
