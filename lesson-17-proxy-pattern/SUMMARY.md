# 📋 Резюме уроку 17: Proxy Pattern (proxy.ts)

### 1. Концепція Проксі
*   **Проксі-патерн** — це використання нашого власного сервера як посередника між клієнтом (браузером) та стороннім API.
*   **Мета:** Безпечне зберігання API-ключів, обхід CORS та трансформація даних перед відправкою на фронтенд.

### 2. Реалізація в Next.js 16
*   Ми використовуємо **Route Handlers** (`route.ts`) замість важкого `middleware.ts`.
*   Це дозволяє використовувати повний Node.js Runtime (бібліотеки, доступ до БД тощо) та зручне кешування через `"use cache"`.

### 3. Робота з заголовками (Headers)
*   **Читання:** `req.headers.get('name')` — використовуємо для перевірки авторизації або отримання метаданих від клієнта.
*   **Запис:** `NextResponse.json(data, { headers: { ... } })` — додаємо власні мітки (наприклад, `X-Proxied-By`) для ідентифікації відповіді нашого сервера.

### 4. Безпека та Помилки
*   **Статус 401 (Unauthorized):** Повертаємо, якщо клієнт не надав правильний ключ/токен.
*   **Try-Catch в TypeScript:** Завжди перевіряємо тип помилки (`e instanceof Error`), щоб безпечно дістати `message`.
