# Урок 27: React Compiler — Забудь про useMemo та useCallback

## 1. Що це таке?
**React Compiler** (раніше відомий як "React Forget") — це новий інструмент від команди React, який автоматично оптимізує твій код. Раніше розробникам доводилося вручну вирішувати, які компоненти або обчислення мемоізувати, щоб уникнути зайвих ререндерів (re-renders). Тепер це робить компілятор на етапі збірки.

## 2. Проблема: Чому ми страждали раніше?
У React кожна зміна стану (`state`) викликає ререндер компонента та всіх його нащадків. Це може бути критично для продуктивності, якщо:
- У тебе є важкі обчислення всередині компонента.
- У тебе велике дерево компонентів, які перемальовуються без потреби.

Щоб це виправити, ми використовували "святу трійцю":
- `useMemo` — щоб кешувати результати обчислень.
- `useCallback` — щоб функції не перестворювалися при кожному рендері.
- `React.memo` — щоб компонент не рендерився, якщо його вхідні дані (props) не змінилися.

**Головний біль:** 
1. Потрібно постійно стежити за масивом залежностей (`[a, b]`).
2. Код стає перевантаженим технічними деталями, які не стосуються бізнес-логіки.
3. Одна помилка в залежностях — і мемоізація або не працює, або створює баги.

## 3. Як працює React Compiler?
Він аналізує твій JavaScript/TypeScript код і автоматично додає логіку мемоізації. Він "бачить", що:
- Змінна `x` залежить тільки від `y`.
- Функція `handleClick` не змінюється, бо не використовує змінні зі стейту.
- Компонент-дитина отримує ті ж самі дані, що і минулого разу.

**Ти просто пишеш звичайний код, а компілятор робить його максимально швидким.**

## 4. Як увімкнути в Next.js 16?
В Next.js 16 (що базується на React 19.2) компілятор вже інтегрований. Щоб його активувати, потрібно додати один прапорець у `next.config.ts`:

```typescript
const nextConfig = {
  experimental: {
    reactCompiler: true,
  },
};
```

*Примітка: У майбутніх версіях це буде увімкнено за замовчуванням.*

## 5. Порівняння

| До (Manual Memoization) | Після (React Compiler) |
| :--- | :--- |
| `const val = useMemo(() => calc(a), [a])` | `const val = calc(a)` |
| `const fn = useCallback(() => {...}, [])` | `const fn = () => {...}` |
| Потрібно огортати компоненти в `memo()` | Компоненти мемоізуються автоматично |

## 6. Правила компілятора
Щоб компілятор працював коректно, твій код має дотримуватися **Rules of React**:
1. Не змінювати змінні під час рендеру (Immutability).
2. Компоненти мають бути "чистими" функціями (однакові пропси = однаковий результат).
3. Хуки викликаються тільки на верхньому рівні.

Якщо код "брудний", компілятор просто проігнорує цей компонент і залишить його як є (оптимізація не спрацює, але код не зламається).
