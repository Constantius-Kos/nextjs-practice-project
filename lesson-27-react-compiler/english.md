# English for Lesson 27: React Compiler

| Term | Pronunciation | Translation | Context |
| :--- | :--- | :--- | :--- |
| **Compiler** | /kəmˈpaɪ.lər/ | Компілятор | Програма, яка перетворює код з однієї мови в іншу (або оптимізує його). |
| **Memoization** | /ˌmem.ə.waɪˈzeɪ.ʃən/ | Мемоізація | Техніка кешування результатів функцій, щоб не рахувати їх двічі. |
| **Bake in** | /beɪk ɪn/ | Вбудувати / "Запекти" | Коли дані фіксуються в коді на етапі білду (статика). |
| **Under the hood** | /ˈʌn.dər ðə hʊd/ | "Під капотом" | Те, як технологія працює внутрішньо, приховано від розробника. |
| **Immutability** | /ɪˌmjuː.təˈbɪl.ə.ti/ | Незмінність | Принцип, за яким дані не змінюються напряму, а створюються їх нові копії. |
| **Out of the box** | /ˌaʊt əv ðə ˈbɒks/ | "З коробки" | Функція, яка працює одразу без додаткових налаштувань. |
| **Overhead** | /ˈəʊ.və.hed/ | "Накладні витрати" | Додаткові ресурси (час, пам'ять), які витрачаються на технічні процеси. |
