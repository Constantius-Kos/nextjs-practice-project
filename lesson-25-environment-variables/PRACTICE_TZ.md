# Практичне завдання до Уроку 25: Env Variables 🔐

## Task 1: Створення секретної змінної
1. Створи (або відкрий) файл `.env.local` у корені `practice-project`.
2. Додай туди змінну `STUDENT_SECRET="NextJS_Master_2026"`.
3. У будь-якому Server Component (наприклад, `app/page.tsx`) виведи цю змінну в консоль (`console.log`) та відобрази на сторінці. 
   *(Спойлер: ти побачиш її в терміналі, але чи буде вона на сторінці? Перевір!)*

## Task 2: Публічна змінна для клієнта
1. Додай у `.env.local` змінну з префіксом `NEXT_PUBLIC_APP_VERSION="1.0.0-alpha"`.
2. Створи новий Client Component (або використай існуючий).
3. Спробуй відобразити `NEXT_PUBLIC_APP_VERSION` на екрані.

## Task 3: Захист від помилок
1. Спробуй вивести `STUDENT_SECRET` (без префікса) у Client Component. Подивись, що виведе браузер (undefined чи помилку?).
2. Напиши просту перевірку: якщо змінна `API_URL` не задана в `.env`, викидай помилку або виводь попередження (це гарна практика для великих проектів).

## Task 4: Шаблон для команди
1. Створи файл `.env.example`.
2. Скопіюй туди назви всіх своїх змінних, але без реальних значень (залиш пусті рядки).
