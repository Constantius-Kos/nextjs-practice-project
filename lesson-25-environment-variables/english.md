# English for Environment Variables (Lesson 25)

| Term | Transcription | Translation | Context in Next.js |
|------|---------------|-------------|--------------------|
| **Environment Variable** | /ɪnˈvaɪ.rən.mənt ˈveə.ri.ə.bəl/ | Змінна оточення | Динамічне значення, що впливає на роботу програми. |
| **Secret Key** | /ˈsiː.krət kiː/ | Секретний ключ | Конфіденційна інформація (паролі, токени). |
| **Expose** | /ɪkˈspəʊz/ | Відкривати / Робити доступним | Зробити змінну доступною для клієнтської частини. |
| **Prefix** | /ˈpriː.fɪks/ | Префікс (приставка) | Початок назви (наприклад, `NEXT_PUBLIC_`). |
| **Mismatch** | /ˌmɪsˈmætʃ/ | Невідповідність | Ситуація, коли дані на сервері та клієнті не сходяться. |
| **Blueprint / Skeleton** | /ˈbluː.prɪnt/ | Креслення / Шаблон | Роль файлу `.env.example`. |
| **Sensitive Data** | /ˈsen.sɪ.tɪv ˈdeɪ.tə/ | Чутливі дані | Дані, які потребують захисту від витоку. |
