# English for Fonts 🔠

1. **Subset** [ˈsʌbset] — підмножина. В контексті шрифтів це набір символів для певної мови (наприклад, `latin`, `cyrillic`).
2. **Loader function** [ˈləʊdə ˈfʌŋkʃn] — функція-завантажувач. Це інструмент Next.js для імпорту шрифтів.
3. **Display: swap** [dɪˈspleɪ swɒp] — стратегія відображення, при якій браузер показує стандартний шрифт, поки завантажується кастомний (щоб користувач не бачив порожній екран).
4. **Variable** [ˈveəriəbl] — змінна. У CSS дозволяє звертатися до властивості через ім'я, наприклад `--font-montserrat`.
5. **Language attribute (lang)** [ˈlæŋɡwɪdʒ ˈætrɪbjuːt] — атрибут мови в HTML, що вказує на мову контенту сторінки.
6. **Hardcoded** [ˌhɑːdˈkəʊdɪd] — жорстко прописаний (код, який важко змінити без редагування файлу).
7. **i18n (Internationalization)** [ˌɪntəˌnæʃnəlaɪˈzeɪʃn] — інтернаціоналізація. Процес адаптації продукту для різних мов та культур.
8. **Hyphenation** [ˌhaɪfəˈneɪʃn] — розстановка переносів у словах.
9. **Glyph** [ɡlɪf] — гліф. Графічне представлення символу в шрифті.
10. **Relative path** [ˈrelətɪv pɑːθ] — відносний шлях. Шлях до файлу відносно поточної папки.
