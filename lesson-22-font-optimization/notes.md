# Нотатки та відповіді (Урок 22)



## ❓ Запитання студента:
1. **Що це за селектор `@theme` у `globals.css`?**
   **Відповідь:** Це **директива Tailwind v4**. Вона дозволяє описувати дизайн-систему (кольори, шрифти, відступи) прямо в CSS. Тепер це "єдине джерело істини" для твого стилю замість JS-конфігу.

2. **Де мій `tailwind.config.ts`? Я його не бачу в проекті.**
   **Відповідь:** Ти використовуєш **Tailwind CSS v4**. У цій версії розробники перейшли на підхід "CSS-first". Замість JS-файлу конфігурації тепер все налаштовується прямо в CSS (`globals.css`) через директиву `@theme`. Це швидше і зручніше для типізації.

2. **`import { Montserrat } from 'next/font/google'` — це імпортується функція з назвою шрифту?**
   **Відповідь:** Так, це спеціальна "функція-завантажувач" (loader function). Next.js автоматично генерує такі функції для кожного шрифту. Коли ти її викликаєш, Next.js "знає", що цей шрифт треба завантажити та оптимізувати під час збірки (build).

3. **`const montserrat = Montserrat({...})` — тут ця функція задає налаштування шрифту?**
   **Відповідь:** Саме так. У цій функції ти конфігуруєш шрифт: які символи потрібні (кирилиця, латиниця), чи використовувати CSS-змінну для Tailwind тощо. Об'єкт `montserrat`, який вона повертає, містить усе необхідне для підключення до твого HTML.

4. **Яке значення та використання налаштування `lang="uk"` у тезі `html`?**
   **Відповідь:** Це атрибут мови (language attribute). Він критично важливий для:
   - **SEO:** Допомагає Google зрозуміти, що контент для україномовної аудиторії.
   - **Accessibility (Доступність):** Скрінрідери (програми для незрячих) зможуть правильно читати текст з українською інтонацією та правилами.
   - **Браузерні сервіси:** Наприклад, автоматичний переклад сторінок або правила розстановки переносів.

4. **А якщо на сайті декілька мов?**
   **Відповідь:** У такому випадку ми не прописуємо мову "жорстко" (`hardcoded`). Next.js має вбудовані інструменти для **i18n** (Internationalization). Зазвичай мова визначається з URL (наприклад, `/en/about` або `/uk/about`), і ми передаємо цю змінну в атрибут: `<html lang={params.locale}>`. Також, якщо на сторінці є блок тексту іншою мовою, можна додати `lang` саме цьому блоку (наприклад, `<p lang="en">...</p>`).

5. **Чи впливає `lang` на верстку "механічно"?**
   **Відповідь:** Здебільшого це метадані, але **так**, він впливає на деякі технічні аспекти:
   - **Hyphenation (Переноси):** Якщо в CSS увімкнено `hyphens: auto`, браузер розставляє переноси за правилами саме тієї мови, що вказана в `lang`.
   - **Quotes (Лапки):** Тег `<q>` автоматично вибирає стиль лапок (`«»` для укр, `“”` для англ) на основі мови.
   - **Font Rendering:** Деякі символи (наприклад, кирилична "і" чи ієрогліфи) можуть відображатися трохи інакше залежно від обраної мови.
   - **CSS селектори:** Ти можеш стилізувати елементи конкретної мови через селектор `:lang(en)`.
