# SUMMARY (Lesson 19)

Тема: Аутентифікація з Auth.js v5 (NextAuth)

### 🔑 Ключові концепції:
1. **Auth.js v5**: Нова ітерація NextAuth, повністю оптимізована під App Router та Server Components.
2. **JWT vs Session**: 
   - **JWT (Token)**: "Паспорт" у кишені (кука). Зберігає дані в зашифрованому вигляді на стороні клієнта.
   - **Session**: Формат даних, який бачить додаток.
3. **Callbacks**:
   - `jwt`: Дозволяє "зашити" кастомні дані (наприклад, `mongoId`) у токен при логіні.
   - `session`: Дозволяє дістати ці дані з токена і передати в компоненти.
4. **Dynamic IO & Suspense**: Використання `auth()` у серверних компонентах робить їх динамічними. Щоб не блокувати всю сторінку, такі компоненти (наприклад, Header) треба обгортати в `<Suspense>`.
