# Практика: View Transitions

Сьогодні ми зробимо так, щоб наш блог відчувався як мобільний додаток завдяки плавним переходам.

---

## 💻 Задачі

### Задача 1: Базова підтримка
Next.js 16 зазвичай підтримує базовий `cross-fade` (плавне розчинення), якщо це не вимкнено. Давай перевіримо це.

1. Зайди в `app/globals.css`.
2. Додай базовий стиль для переходів:
```css
@view-transition {
  navigation: auto;
}
```

### Задача 2: Анімація постів блогу
Ми хочемо, щоб коли ти клікаєш на картку блогу, заголовок поста "перепливав" на своє нове місце на сторінці самого поста.

1. Відкрий сторінку списку блогів (`app/blog/page.tsx`).
2. Для тексту заголовка у списку додай унікальне `view-transition-name`. Оскільки постів багато, ім'я має бути динамічним (наприклад, `title-${p.id}`).
3. Відкрий сторінку самого поста (`app/blog/[slug]/page.tsx`).
4. Знайди там заголовок `<h1>` і дай йому таке саме ім'я.

### Задача 3: Кастомізація швидкості
Давай зробимо перехід повільнішим, щоб ми могли його побачити.
1. У `globals.css` налаштуй тривалість анімації для `::view-transition-old` та `::view-transition-new`.
