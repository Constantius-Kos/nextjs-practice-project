# English for Lesson 23: View Transitions

| Word / Phrase | Translation | Context in Next.js |
|---------------|-------------|--------------------|
| **View Transition** | Перехід вигляду | Технологія анімації між станами/сторінками. |
| **Snapshot** | Знімок / Скріншот | Тимчасове зображення сторінки під час переходу. |
| **Old state** | Старий стан | Те, що було на екрані ДО переходу. |
| **New state** | Новий стан | Те, що з'являється ПІСЛЯ переходу. |
| **Smooth** | Плавний | Опис якісної анімації. |
| **Hero animation** | Героїчна анімація | Коли головний об'єкт (hero) перелітає з місця на місце. |
| **Duration** | Тривалість | Час, скільки триває анімація. |
