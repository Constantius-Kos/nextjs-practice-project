# 📋 Резюме уроку 12: Parallel Routes (Паралельні маршрути)

### 1. Slots (Слоти) — папки з @
- Створюються за допомогою папок, назва яких починається з `@` (наприклад, `@projects`, `@info`).
- Ці папки **не відображаються в URL**. Шлях `/dashboard/@projects` у браузері буде просто `/dashboard`.
- Вони дозволяють розділити одну сторінку на кілька незалежних зон з власним контентом.

### 2. Layout та пропси
- Усі слоти автоматично передаються як пропси в `layout.tsx` тієї ж папки.
- Наприклад, `layout.tsx` для дашборду отримує `{ children, projects, info }`.
- `children` — це стандартний слот для основного `page.tsx`.

### 3. Незалежність (Streaming & Error Handling)
- **loading.tsx**: Кожен слот може мати своє завантаження. Весь сайт не чекає на повільний блок — він з'явиться за допомогою Suspense, коли дані будуть готові.
- **error.tsx**: Помилка в одному слоті (наприклад, у статистиці) не «вбиває» весь дашборд. Користувач побачить повідомлення про помилку лише в цьому конкретному блоці.

### 6. Intercepting Routes (Перехоплення) 🔀
- Дозволяють показувати контент іншого маршруту в поточному лейауті (наприклад, модальне вікно).
- **Синтаксис**: `(.)` — поточний рівень, `(..)` — рівень вище, `(...)` — від кореня `app`.
- **UX**: Користувач бачить модалку поверх сторінки, але при F5 потрапляє на повноцінну сторінку цього маршруту. Це зберігає контекст і дозволяє ділитися посиланнями.

---

### 💡 Ключові висновки нашої практики:
1.  **Soft Navigation (Клік)**: Next.js намагається зберегти стан слотів. Якщо в слоті немає точного збігу для нового URL — він залишає старий контент («заморожує» його). 
2.  **Hard Navigation (F5)**: Next.js ініціалізує все з нуля. Якщо він не знаходить точну папку для слота — він шукає `default.tsx`.
3.  **Default.tsx як база**: Якщо ти хочеш, щоб контент у слоті був однаковим для всіх вкладених шляхів — краще перенести його в `default.tsx`.
4.  **Синтаксис дужок**: Назва папки має бути `(..)назва_маршруту` (без пробілів). Це «гачок», який чіпляє відповідний сегмент URL.

### 4. Навігація — «Золоте правило» 🚦
Це найважливіший момент, де часто виникають помилки:
- **Soft Navigation (Клік по лінку)**: Next.js зберігає поточний стан слотів, які не змінилися. Якщо ти перейшов на іншу сторінку, а для якогось слота там немає контенту, він просто залишиться таким, як був.
- **Hard Navigation (F5 / Оновлення сторінки)**: Стан втрачається. Next.js шукає `page.tsx` для поточної адреси в КОЖНОМУ слоті одночасно.

### 5. Роль default.tsx
- Якщо при оновленні сторінки (Hard Navigation) Next.js не знаходить `page.tsx` у конкретному слоті для поточної адреси, він шукає `default.tsx`.
- Якщо `default.tsx` немає — виникне помилка **404**.
- **Порада**: Завжди створюй `default.tsx` для слотів, щоб уникнути 404 при перезавантаженні сторінки.
