# 📋 Резюме уроку 4: Метадані і SEO (metadata API)

### 1. Metadata API — вбудований SEO
- Більше не потрібно ставити бібліотеки `react-helmet`. Next.js має вбудовану систему управління тегом `<head>`.
- **Декларативність**: Ти просто експортуєш об'єкт або функцію з файлу сторінки, а фреймворк сам будує HTML на сервері.

### 2. Статичні метадані
- Найпростіший спосіб: `export const metadata: Metadata = { ... }`.
- Використовуй для сторінок, де заголовок та опис не змінюються (Головна, Про нас, Контакти).

### 3. Динамічні метадані (Next.js 16)
- **Функція `generateMetadata`**: Дозволяє отримувати дані з БД або API перед тим, як віддати сторінку користувачу.
- **Важливо**: В Next.js 16 пропси `params` — це **Promise**. Обов'язково пиши `const { id } = await params`, інакше отримаєш помилку.

### 4. Template (Шаблони заголовків)
- В `layout.tsx` можна задати шаблон: `title: { template: '%s | MySite', default: 'MySite' }`.
- Тепер якщо в сторінці ти напишеш `title: 'Проєкти'`, у браузері буде: **"Проєкти | MySite"**. Це економить купу часу та підтримує єдиний стиль.

### 5. OpenGraph та Соцмережі
- Поле `openGraph` дозволяє налаштувати прев'ю посилання (Title, Description, Image) спеціально для Telegram, Facebook, Twitter.
- **Картинка**: Next.js може автоматично генерувати OG-зображення, якщо покласти файл `opengraph-image.(png|jpg)` у папку маршруту.
